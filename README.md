# Euphronic

Euphronic is an open lab about AI for people who don't program. I'm George, and I can't code. I build websites, automations and small tools with Claude Code: I describe what I want, check the result and make the decisions, and the agent writes the code.

On [euphronic.com](https://euphronic.com/en/) I write up what worked, what didn't and the setup behind it, in English and Czech. Nothing there is for sale. George is a pseudonym.

## Repositories

- [claude-code-templates](https://github.com/euphronic/claude-code-templates): a starter CLAUDE.md, a read-only critic subagent, two small safety hooks, permission settings and the prompts I use every day.
